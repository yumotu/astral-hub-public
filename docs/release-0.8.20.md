# 0.8.20 — 对话准备、学习资料与加载恢复

- 新对话先展示可输入的聊天界面，后台准备所选电脑、项目和执行器。首条消息与附件在准备完成后安全交接；切走后返回再投递，未知回执不自动重发。草稿按账号、服务器和窗口协调保存，避免双窗口互相覆盖。
- 电脑目录优先使用本账号的显示缓存，后台更新；补充电脑项目入口。目录缓存不代替实时文件、执行和扩展授权。长待处理信息限制高度，工具详情和 Markdown 按需加载，减少历史对话打开时的处理量。
- DSH 对话可准备 Skill、MCP 和固定版本 npm bundle 方案，在聊天中查看、编辑并确认。保留精确操作预览、权限校验与未知结果核对，不由模型自行安装或批准。凭据仍在设置表单填写。
- 学习页支持使用有界的 UTF-8 TXT／Markdown 材料分章生成，保存章节检查点，失败后从原课程显式恢复。材料选择按课程隔离；恢复需确认，不自动重建课程。
- 修复学习页读取失败、刷新过滤条件、已加载多页记录丢失和旧请求覆盖恢复结果；折叠答案只在展开时渲染。邮件、文件和联系人各自加载，失败不拖住其他页面；已读判定与可见的最新消息一致。
- Pi 对保存学习资料的要求增加工具调用引导，省略题量时默认5道选择、2道问答，仍受管理员上限约束。工具回执明确区分课程生成中、已完成和失败。另增加服务端的生成证据缺失提示字段，当前界面尚未显示该字段；提示规则不保证模型必然调用生成工具。
- 改进 Mac 构建的临时签名检查。网页、服务器及 macOS arm64／x64、Windows x64、Android 安装包统一0.8.20，Android versionCode64并沿用原证书。

保留已有账号、项目、电脑、文件、对话及独立服务器配置。Mac 临时签名未公证，Windows 未正式签名，Android 物理设备检查仍待后续。第三方扩展是否可用以目标主机的实际加载和调用结果为准。学习材料单次最多16件，单件64 KiB／32000字符，总计256 KiB／96000字符，最多24章；这些范围不等于模型质量或费用保证。
