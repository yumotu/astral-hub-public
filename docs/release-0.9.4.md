# 0.9.4

0.9.4 adds account-scoped real holdings and explainable portfolio research.

- Holdings support domestic and international equities, funds, gold, FX, bonds, cash, and cash-management assets.
- Users can add, delete, and refresh holdings. Allowlisted public quote sources refresh domestic equities, funds, gold, and supported FX pairs when available.
- Portfolio recommendations combine risk-budget targets, market-regime views, CVaR and drawdown guards, concentration checks, and a 5% turnover threshold.
- The investment page keeps long labels inside the viewport on mobile layouts and adds holdings and recommended-actions views.
- Existing 0.9.3 assets remain available for rollback. macOS temporary signing, Windows unsigned builds, and Android debug-signing limitations remain unchanged.
