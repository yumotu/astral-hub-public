# 星屿 0.8.12

本版将已上线的 DSH 聊天、软件工具与附件能力带入 macOS、Windows 和 Android 安装版。默认助手继续使用 Pi；既有账号、项目、电脑配对、文件和原生上下文保持。

- 同一智能助手界面可选择 Pi 或已连接的 DSH Remote。DSH 支持原生流式回复、问答和审批、停止、重连、项目分类及对话菜单，操作偏好在重新打开后保留。
- DSH 对话可显式启用星屿软件功能，使用已有邮件、联系人、学习和账号记忆。发消息、发邮件等操作保留真实业务预览与当前账号确认，已读和查询直接执行。
- DSH 共用附件上传、粘贴、图片与文档预览、原件下载和生成文件卡片。上传上限50 MiB，传给主机的原件上限20 MiB；文件交付每个10 MiB、每任务8件/20 MiB。PDF和图片可在服务器离线识别中英文。
- 附件仅提供给明确提交它们的账号和任务；取消、退出登录和撤销授权后不再返回内容。原件缺失与解析失败分别显示，未知发送结果不自动重发。
- 保留0.8.11的远程Pi请求容量修复：原生模型请求最多16 MiB，取消额外的1000条消息限制；格式错误与容量超限分别返回400/413。
- 修复手机横屏关闭键盘后，连接错误提示挤出输入框和发送按钮的问题；Pi/DSH切换时的包装层继续共享短窗口布局规则。

服务器运行包和源码包含 dsh2 的 DSH 主机及工具插件源码。已有外部 Remote 主机需自行更新工具插件并明确配置授权工作区；安装客户端不会自动修改外部主机。自托管时DSH仍需独立配置并显式启用，Pi保持默认。DSH终端、目标/定时和统一账号费用尚未接入。

macOS继续临时签名，未取得Apple Developer ID或公证；Windows未正式签名；Android沿用原证书。自动化、原生运行和模拟器结果与物理设备验收分别记录，不将构建通过当作真机验收。
