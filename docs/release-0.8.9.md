# 0.8.9：电脑连接、统一聊天与账户用量

聊天草稿在焦点移到历史区域后也可用Enter发送；空草稿恢复输入焦点。Shift+Enter换行、输入法确认、搜索/终端/弹窗按键保留，两类聊天共用同一处理。

- Mac/Windows安装包内置电脑执行器和Node，无需另装运行环境。通过「电脑连接」在本机选目录、分别授权读写和命令执行；默认不开启，不自动继承已有命令行执行器的授权。
- 本机、远程电脑和服务器项目共用助手聊天入口及输入按钮。思考、语音、附件、命令、连续补充、发送/停止采用同一布局。Bash联网、授权、权限与补充方式收进原工具栏位置的折叠「设置」；电脑的本机授权保持独立，终端始终指向所选电脑。
- 电脑对话支持右键/长按菜单，重命名、置顶、归档/恢复、同项目新建和删除。项目默认展示最近3个对话，更多先展开缓存，随后分页；删除不触碰项目文件，运行中的对话需先停止。
- 电脑聊天支持50 MiB附件输入，按任务授权读取真实Word、PDF、Excel文字。校验与私有缓存避免重复传输，撤销后立即拒绝访问；图片原件可预览下载，电脑模型仍只接收文字。
- 「连接与设置 → 账户用量与费用」展示实际Token、缓存命中/未命中和输出，按DeepSeek官网人民币单价及峰谷时段核算。管理员可看各账户，普通成员仅看自己，支持日期筛选和明细；当前只核算费用，不扣余额。缺失用量、未核验模型及旧历史不会补造为已计费记录。
- 助手软件工具同步增加电脑对话管理和用量查询；目录授权仍由本机用户操作。网页「软件更新」可下载Mac两架构、Windows、Android客户端。

本机命令使用当前系统用户权限，项目目录不是Shell沙箱。Mac默认临时签名，Windows默认未正式签名，Android更新须保持既有证书；不能把构建或模拟器结果当作物理设备证明。实际发行状态和校验流程见[构建发行版](releasing.md)。
