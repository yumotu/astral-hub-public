# 账号画像与跨对话记忆

在连接与设置中管理长期记忆。记录按账号保存，可搜索、添加、纠正、删除和关闭；同账号连接同一服务器时可跨设备使用。

记录区分事实、偏好、目标、任务和推测，保留来源原话、时间、范围和版本。Agent只能引用当前用户任务或已应用补充中的原话，不能把邮件、文件或其他账号内容直接当作用户事实。纠正同一事实时更新原记录，旧版本写入返回冲突；删除后清除内容，旧请求不能恢复该编号。

每次任务按当前问题相关性读取最新记录，最多8条、6000字符；项目记忆只在对应服务器项目或对应电脑项目中召回，账号偏好可跨项目。当前用户的更正优先于旧记忆。关闭后不自动召回，也不允许Agent继续写入；已有记录仍可查看和整理。

共享软件工具目录提供`memory.list/recall/remember/revise/delete/settings`。普通聊天不会因为记忆而启动Goal。记忆是带来源的数据，不提供文件、执行命令、发送消息或连接电脑的权限。

数据保存在服务器SQLite中，没有端到端加密；应将数据库与已有应用数据一起备份。连续发送仍是当前设备偏好，与服务器账号记忆分别管理。
