# 星屿 0.8.14

- 项目与对话统一管理 Pi、电脑 Pi 和 DSH。左上角设置新对话的默认引擎，已有对话在设置中切换；保留标题、原历史和实际来源。
- 切换引擎采用新的原生会话段，交接有界的可见正文；运行、排队、等待回复及停止未确认时阻止切换。不会复制隐藏思考、工具执行、附件字节或授权，也不会重跑原任务。
- 临时对话可参考所属主对话的可见上下文；同一主对话复用原侧边历史，关闭重开和再次划选可接着聊，不同主对话分别保留。侧边对话默认闲置1小时后过期，可选6小时、24小时或7天；打开/发送续期，轮询不续期，执行中暂不清理，手动保留到对话列表后永久保留。继续保持独立回答和原有账号/项目权限。
- 普通助手回复默认不加外框；明确生成的文稿成品使用加深卡片并支持独立复制，文件预览保持原Markdown格式。
- 修复手机项目抽屉底部遮挡、长名称和安全区布局；支持刷新恢复当前会话，保留右键/长按管理与项目最近三条对话。
- 新增软件工具查询统一对话目录、修改展示名称/置顶/归档。模型不能静默切换引擎。

旧电脑执行器需要更新后才可作为统一对话的新建/切换目标，旧历史仍保留。电脑 DSH 的一键安装/配对尚未接入；DSH目标/定时和统一计费不在本次范围。跨引擎交接属于有界可见文本交接，不等于复制完整原生上下文。

macOS沿用临时签名，Apple Developer ID及公证未完成；Windows未正式签名。Android沿用原证书以支持覆盖更新。物理设备验收范围以正式交接为准。
