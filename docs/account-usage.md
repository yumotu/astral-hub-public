# 账户用量与费用核算

入口：连接与设置 → 账户用量与费用。普通成员仅查询自己的用量；管理员可按账户、北京时间日期查看合计及调用明细。`GET /api/usage` 与助手 `app_functions / usage.summary` 复用相同账号权限。

## 数据来源

记录上线后的服务器模型请求，包含服务器 Pi、电脑模型代理、学习生成/判题、邮件整理/摘要、塔罗、插件生成及对话标题。每次实际请求都有独立记录，流式重传和重复查询不会再次计费；任务、对话删除不删除用量账本。电脑设备仍不能取得服务器模型密钥。

来源是模型响应的实际 usage：缓存命中、未命中、输出分别记录。DeepSeek 的输出 Token 已包含推理输出，不重复加 reasoning_tokens。Pi 的 input 是未缓存输入，cacheRead/cacheWrite 单独转换；不把整个 prompt_tokens 再加一次缓存。失败、截断但返回 usage 的响应也统计；未返回或不完整的用量标记未知，费用不计为零。

旧历史没有足够的逐请求模型、时间、缓存信息，不回填虚构账单。本机直接使用自有密钥以及第三方插件自行发起的模型请求不经过服务端，未纳入统计。当前没有余额账户、充值或欠费拦截，不扣用户余额。

## 官方人民币价格版本

核验日期：2026-11-05。来源：[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。每百万 Token：

| 模型 / 时段 | 缓存命中 | 未命中 | 输出 |
| --- | ---: | ---: | ---: |
| deepseek-flash 空闲 | ¥0.02 | ¥1 | ¥4 |
| deepseek-flash 高峰 | ¥0.04 | ¥2 | ¥8 |
| deepseek-v4-pro 空闲 | ¥0.15 | ¥4.5 | ¥13.5 |
| deepseek-v4-pro 高峰 | ¥0.30 | ¥9 | ¥27 |

旧别名 deepseek-v4-flash、deepseek-v4-flash-vision-exp 按 Flash；其他未核验模型保留 Token、标为费用待核算。北京时间周一至周五09:00–12:00、14:00–18:00为高峰，周末及中国法定节假日为空闲。2026年节假日区间依[国务院办公厅通知](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)记录；未来年份高峰候选时段缺节假日核验时暂不定价。

每次调用保存请求开始时间、价格版本、实际单位价格与时段，使用整数nano-CNY累加，避免逐次浮点舍入。此处是按请求开始时官方单价核算的估计金额，不是DeepSeek实际扣费回执；跨时段请求、优惠及官网之后调价均以提供商账单为准。独立Search/Fetch API按次收费，不混入Token价格。

价格文件 `shared/deepseek-pricing.mjs` 的历史版本不覆盖：官方调价时新增生效版本和核验来源，再测试边界；已记录调用不追溯改价。数据库`ai_usage`仅保存账号、来源、关联任务ID、时间、模型、数量和价格，不保存提示词、邮件正文或模型密钥。

## 验证边界

测试覆盖北京时间峰谷边界、官方别名、精确金额、缓存转换、缺失与非法用量、并发账号隔离、重启、重复事件、响应截断、真实业务HTTP入口、电脑代理SSE分片及Pi任务回传。真实模型及正式发行验收另见0.8.9交接，不以合成测试替代。

补充：Pi 1.4 的上下文压缩与缓存预热不一定进入普通回复事件，因此单独采集SDK实际回传的辅助用量。普通计量记录对应一次模型响应，压缩记录可能汇总多次摘要请求，费用按压缩过程开始时段估算；不把一次压缩虚构为确定次数的请求。预热只提供结束后的记录时，保留Token并标明请求起始时刻未知、费用待核算，不用完成时间冒充计费开始时间。价卡相同ID的内容不一致时启动检查拒绝覆盖。
