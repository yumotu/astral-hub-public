# 定时任务与持续目标

管理员可以在当前服务器、本机或远程电脑对话中用自然语言管理计划，或使用 `/cron`。后端固定使用 `@patimweb/pi-cron@2.2.0` 的时间解析和无模型宿主；每个到期任务进入星屿持久队列，执行过程和结果保存在原对话。网页不需要一直打开，应用服务器和调度宿主需要运行。

- `schedule_manage` 或软件工具目录的 `schedules.manage` 支持 list、status、results、create、update、run、pause、resume、remove。
- `/cron add` 依次填写名称、时间、完整任务和执行方式；`/cron list`、`status`、`results` 查询，`run <计划>` 立即执行，`pause`、`resume`、`remove` 管理计划。
- 时间默认 Asia/Shanghai，例如 `daily 9:00`、`every 30m`、`in 2h`。名称在同一管理员的调度宿主内保持唯一，现有每管理员十个计划的容量边界保留。
- 普通计划每次执行一个任务；`longGoal: true` 为每次发生创建独立的 `/long-goal` 目标，按完整验收要求持续工作。没有隐藏的默认 Token 预算；发送邮件、联系人消息和命令授权仍走各自的预览与确认。

创建计划时，服务端从正在执行的主对话取得账号、项目、执行位置、读写模式和命令权限。模型不能提交其他账号、电脑、目录或更大的权限。计划只在其原对话、项目和目标中可见；降低当前模式后仍可查询、暂停或删除，修改、恢复或立即运行要回到创建时的模式。暂停不会重写原计划捕获的权限。

电脑离线时任务等待原电脑，绝不转到服务器执行；目标电脑需更新到支持定时任务的执行器。每次准入和本机执行都重新检查账号、目录、文件修改和命令授权。永久撤权或目标消失会停用计划，不能靠定时器恢复旧授权。可显式指定工具子集；实际 Pi 会话也只注册这组工具，空集合不会回退到完整工具权限。

计划和每次发生有持久编号，服务或宿主重启不重放已接收或完成的发生。调用结果未知时，用 `app_functions` 的 status 查询原 callId；不要重新创建或再次运行。未知的外部操作要先检查原记录。中断、撤权和错过的任务不会伪装为成功。

开发验证包含真实固定版 cron 宿主的定时触发、重启、权限和去重，以及实际电脑 Pi 工具调用、原位置分发、受限工具集合和无模型 `/cron list`。合成模型验证与实际模型、正式发行验收分别记录。
