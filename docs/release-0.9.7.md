# 星屿 0.9.7

## SuperAgent 管家

- SuperAgent 改为微信式持续聊天窗口，使用消息气泡、头像、时间和短思考状态。
- Leader 只负责理解目标、澄清边界、委派和汇报，执行统一交给 subagent。
- 委派任务、进度、等待用户、失败和完成回执会回到同一条 SuperAgent 对话。
- 对话按账号保存在本机，刷新页面后继续。
- 未登录时仍可整理目标，但不会伪造或创建真实执行任务。

## 真实工作台

- 移除工作台中的合成事件快照、DPH 仿真按钮和合成工具路由。
- 工作台读取当前账号的 Pi 对话与任务、SuperAgent 委派任务、Pi 目标、投资持仓／行情／计划和邮箱摘要。
- 未连接的数据源显示为空状态，页面明确标注当前账号数据，不生成演示事项。
- 保留今日时间轴、风险提醒、任务列表、长期目标、定时计划、邮件事项和资产提醒布局。
- 工作台只读汇总，不会因为打开页面自动发送邮件、执行交易或启动任务。

## 兼容与限制

- 既有 Pi、DPH、Remote 对话路由保持。
- macOS 使用临时签名，未进行 Developer ID 公证。
- Windows 未使用正式代码签名。
- Android 沿用调试签名，覆盖安装前需要卸载旧版并保留数据。
