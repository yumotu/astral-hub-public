# 0.8.18 — 项目与电脑管理

- 服务器和电脑项目统一支持右键、长按及更多菜单，可修改显示名称、移除项目和恢复已移除项目。名称仅影响软件展示，不修改实际文件夹。
- 移除项目只清理当前账号的导航入口，保留文件、对话历史与草稿；在“更多 → 已移除”恢复。进行中的任务、文件操作或未确定的创建／切换会阻挡移除。
- 删除电脑按精确的 Pi 设备或 DPH 连接撤销，刷新、心跳及重新打开应用不会恢复已删除连接。Pi 会停止该连接任务与终端；DPH 远端任务可能继续。服务器自身 DSH 不作为电脑删除。
- 智能助手同步获得项目查询、显示名修改、移除、恢复和电脑删除工具；移除及撤销连接先显示准确预览。
- 保留电脑连接恢复、每对话 Pi／DPH 选择、服务器／电脑 → 项目 → 对话的统一层级；历史可读，撤销后的执行与修改禁止。

网页、服务器及 macOS arm64／x64、Windows x64、Android 安装包统一为 0.8.18。Android versionCode 62，沿用原证书；Mac 临时签名未公证，Windows 未正式签名，Android 真机验收仍待后续。正式发布及验证状态以交接记录为准。
