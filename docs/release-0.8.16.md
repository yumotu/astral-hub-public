# 0.8.15.r1 — 项目与对话层级整理

本次修订对外名称为 **0.8.15.r1**。为兼容已有客户端的软件更新协议，安装包、下载资产和技术版本使用 **0.8.16**；Android versionCode 为 **60**。二者是同一版，非另外一个功能版本。

- 右侧统一按「服务器／各台电脑 → 项目文件夹 → 对话」组织，Pi 和 DPH 对话在同一棵树中管理。
- 每个项目默认显示最近三条对话，点击更多查看其余历史；搜索覆盖全部对话标题、项目和电脑名称。
- 搜索展开匹配项目，清空后恢复手动折叠状态；修复快速折叠与搜索的竞态。
- 默认目录、归档、连接管理与刷新收进底部更多；手机浅深色与横屏布局修复底部遮挡、长名称及横向溢出。
- 保留对话右键／长按、置顶、归档与项目显示名称修改；切换 Pi／DPH 不改变原项目归属。同名电脑和项目不会凭名称猜测合并。

没有新增数据库迁移或授权范围。既有侧边对话上下文、有效期、DSH dsh4 工作台及扩展能力继续保留。Mac 使用已接受的临时签名，未做 Apple 公证；Windows 未正式签名；Android 沿用原证书，物理设备验收仍待后续。
