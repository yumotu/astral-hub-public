# 0.9.1

0.9.1 以已验收的 0.8.20 为运行基线，统一服务器、本机电脑、远程电脑和 DPH 工作区的资源树与对话语义。

- 持久化本机连接档，支持按服务器与账号区分多个电脑连接，切换项目和对话时复用连接。
- 新配对支持完整工作区权限，包含文件读写、终端、网络、插件、DPH 工作区和后台任务，并在服务器与执行器两端核对。
- 统一位置、工作区文件夹、项目和对话层级，支持从目录创建项目、修改软件显示名、移除与恢复。
- 每个对话独立选择 Pi 或 DPH，缓存优先恢复历史、草稿和目录，实时权限和执行状态继续联网核对。
- 继续保留 0.8.20 的学习、邮件、附件、插件和后台任务能力。

本版发布前必须通过完整 web／服务器／Pi／电脑执行器／桌面／Android CI、原 Android 签名校验、四平台原包核验、更新清单复核和服务器空闲切换复核。Mac 采用临时签名时会明确记录未公证限制，Windows 签名与 Android 物理设备验收分别记录实际结果。
