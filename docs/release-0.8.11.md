# 星屿 0.8.11

修复远程电脑长对话调用模型时出现的 `400「模型请求格式不正确或过大」`。

- 远程项目的模型代理改为最多 16 MiB 的 UTF-8 JSON 请求，统一读取与校验容量，去掉原约 1 MB 和 1,000 条消息的额外限制。原生上下文、工具记录及图片内容完整转交，不自动删改对话。
- 格式错误与容量超限分别返回明确原因；其他普通 JSON 接口仍为 2 MiB，旧版一次性执行器保持较小容量。
- 大请求读完后重新核对设备授权、任务状态、租约和项目权限，保留停止、并发、流式输出及账户用量记录。

这是基于 0.8.10 与已上线沙箱修复的独立修复版，不包含开发中的 DSH 接入及附件改动。现有账号、项目、配对和原生会话继续保留。更新服务端后，原电脑执行器即可受益；失败任务不会自动重发，可在原对话中重新提交。

macOS 继续采用临时签名，尚未公证；Windows 尚未正式签名。Android 延续原应用证书；模拟器验收与物理设备验证分别记录。
