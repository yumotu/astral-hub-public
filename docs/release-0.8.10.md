# 星屿 0.8.10

- 增加账号画像与跨对话记忆：可管理事实、偏好、目标与任务信息，保留来源和版本；支持纠正、删除、关闭，按实际项目相关性召回。记忆不赋予文件或电脑权限。
- 服务器、本地和远程电脑统一聊天设置、回到最新、提问按钮与其他答案输入。连续发送集中到连接与设置的当前设备偏好；文件修改使用开关，项目授权移至管理员连接与设置。
- 思考和附件依据真实执行器能力展示可用状态，不可用时可查看原因；项目显示名保存修复跨域预检，实际目录不变。手机底部显示完整的实际会话统计。
- 长程任务持久保存同一Goal的TODO、验收标准与证据，必要时等待用户回答；中断后显式续接，未通过验收不能标记完成。
- 执行记录默认折叠，可手动展开；运行中隐藏回复底部统计、复制和文件说明，区分执行、等待回复、正在停止与已停止。会话总信息保留。
- 普通任务完成不再自动通知；新邮件、联系人消息和好友申请加入通知，点击进入对应页面，重复事件去重，首次邮件同步不提醒历史邮件。
- 数学公式支持LaTeX常用分隔符和离线字体。学习题目提供读取、版本修改和历史接口，并同步Agent工具；旧作答和成绩保留原题版本，后续判题采用修正版。
- 公开源码采用MIT许可证，分发包保留第三方许可声明。原private仓库及历史、设备配对和项目权限保持。

新版电脑功能需要配套执行器；原独立CLI不会自动重新配对或扩大授权。macOS保留已接受的临时签名与未公证限制，Windows未签名；Android沿用原签名。物理设备验收另行确认。
