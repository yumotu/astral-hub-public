# 星屿 0.8.13

本版将已上线的 DSH 工作台与扩展管理带入 macOS、Windows 和 Android 安装版。默认助手继续使用 Pi；既有账号、项目、电脑配对、文件、历史与原生会话保持。

- DSH 与 Pi 共用聊天输入区。DSH 终端、思考强度、原生技能和待审核/工作区/完全权限设置均可在聊天工作台使用，以连接主机实际支持的能力为准。
- 重新打开应用时恢复同一账号、服务器的上次对话；暂时断网保留视图，重连后补回进度，不重发已接受消息。修复恢复后残留的超时提示。
- DSH 对话「设置 → 扩展管理」统一管理 Skill、固定版本 npm 原生插件和 MCP。支持技能导入、编辑、启停及恢复，插件安装、更新、启停、移除恢复，以及 stdio/Streamable HTTP MCP 配置。
- 扩展管理限定当前登录管理员及已关联主机。聊天可查询目录、准备更改预览；用户确认后才应用。原生插件按 Profile、Skill/MCP 按工作区管理，正在执行的任务不因安装被重放或中断，未知结果按原操作编号核对。
- 插件固定版本并核对实际加载，失败尝试恢复旧版本；MCP 配置加密保存，列表隐藏凭据。修复只读主机中 pnpm 安装缓存写入错误，保留不自动执行安装脚本的设置。
- 保留已有附件上传/粘贴、PDF与Office预览、离线识别、原件下载及真实文件交付；邮件、联系人、学习和记忆继续共用已有账号权限。

服务器运行包和源码包含 dsh4 能力的完整主机与扩展桥，固定 Harness 0.2.2-rc.1、Remote 14037e78及pnpm 11.25.0。第三方插件需要兼容该运行时；安装客户端不会自动修改外部 DSH 主机。远程电脑一键安装与配对 DSH、DSH 目标/定时和统一费用不在本版范围。

macOS 延续临时签名，未取得 Apple Developer ID 或公证；Windows 未正式签名；Android 沿用原证书。构建、签名完整性、模拟器及实际设备验证分别记录。
