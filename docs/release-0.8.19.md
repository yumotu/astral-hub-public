# 0.8.19 — 重开缓存与对话显示修复

项目、电脑、对话历史、学习内容及未读数增加七天持久显示缓存，重新打开时先显示历史，再后台同步。缓存按账号和服务器隔离；退出清理，不把缓存当成实时授权或执行状态。DSH历史恢复期间禁用执行入口，确认实时状态后恢复，避免重复发送和旧操作复活。

新建DSH对话默认开启已配置的软件功能，显式开关按账号、连接和工作区记住；已有关闭选择保持。电脑文件与命令权限、授权期限和发邮件／联系人消息的确认流程保持。

修复隐藏思考后产生空白消息和孤立“复制”按钮的问题，当前与历史对话使用一致规则；原始思考、工具记录和任务状态保留。

网页、服务器及macOS arm64／x64、Windows x64、Android安装包统一0.8.19，Android versionCode63并沿用原证书。Mac临时签名未公证，Windows未正式签名，Android真机验收仍待后续。实际发布和验证结果以交接记录为准。
