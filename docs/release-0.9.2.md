# 0.9.2

0.9.2 以 0.9.1 为运行基线，修复项目目录树和邮件 Agent 的执行反馈。

- 服务器源项目现在作为工作区根节点，子项目按 `sourceId` 归入对应项目文件夹，独立对话显示为独立对话分组，电脑和 DPH 项目不会因为缺少工作区字段而重复套层。
- 邮件 Agent 在读取、分页、整理和等待确认时显示实时工具活动，保留原有确认、取消、未知结果核对和不重复执行规则。
- DSH4、Pi、数据库、插件、授权和独立配置沿用 0.9.1，金融研究插件仍由独立 bridge 管理，不作为本版内置插件发布。

本版发布前必须通过完整 web、邮件 Agent、服务器、Pi、电脑执行器、桌面、Android CI、原 Android 签名校验、四平台原包核验、更新清单复核和服务器空闲切换复核。macOS 临时签名、公证和 Android 真机结果按实际验收记录说明。
