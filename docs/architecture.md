# 架构

`web/src` 是 React/Vite 共用界面，`desktop` 为 Electron 外壳，`android` 为 Capacitor 工程。`server` 提供 Node HTTP API、账号、SQLite、邮件、学习与电脑中继；`shared` 保存共同协议、校验和费用计算。

`deploy/pi` 是固定 Pi SDK 的服务器桥接与隔离工具；`agent` 是电脑执行器。电脑主动连接 HTTPS 中继，凭据保存在本机私有配置，模型主密钥保留在服务器。服务器项目和电脑项目复用界面，但不共享执行权限或失败回退目标。

任务通过稳定请求编号和持久回执恢复；未知结果查询原编号，不自动重放。文件传输校验账号、对话、项目、任务租约和摘要，历史附件独立保存。用量账本保存实际 usage 与对应价卡，不保存模型提示词、邮件正文或密钥。

软件操作统一经 `app_functions` 服务校验；关键副作用使用精确预览与幂等确认。用户文件、SQLite、邮件凭据、模型密钥与设备配置均属于部署数据，不随源码或安装包发布。
