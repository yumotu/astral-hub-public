# DSH 工作台：终端、思考、技能、附件和权限

状态：2026-11-12已部署服务器/网页dsh3，并在dsh4扩展管理部署中复验通过；原生安装包本地界面待后续夜间新包。开发记录见[发行说明](release-0.8.13.md)，当前验证与回退见[发行说明](release-0.8.13.md)。

## 使用

- 输入框的终端按钮打开当前DSH工作区终端，可新建、切换、输入、调整尺寸、Ctrl+C和结束。远程主机需要在其Remote设置开启终端；本轮为受管理服务器的下一次镜像构建启用该能力，没有修改当前生产进程。
- 思考按钮读取当前模型真正支持的档位，提交原生`session/selectModel`；没有提供的档位不会伪造。模型名称支持供应商原有的命名空间形式。
- `/`按钮列出工作区技能，可搜索；选择后只把`/技能名`填入草稿，发送后由原生Harness加载。目录不等于安装新技能。
- 附件按钮或粘贴文件直接开始上传，显式选中文件后开启此对话的软件功能，无需先寻找开关。仍沿用50MiB单文件、20MiB原件传至主机、10MiB单个导出/20MiB每任务总导出的S4限制。大文档可通过分页文本/OCR读取。附件卡片放入共用输入框，适配短键盘视口。
- 上方折叠设置内按原生目录展示权限。**待审核**对应`read-only`，默认不允许写入；需要扩大范围的操作在对话中审核。**工作区**对应`workspace-write`，超出允许范围需要审核。**完全权限**对应`danger-full-access`，不再逐次审核文件和命令；仍限主机执行账号和现有容器边界，不会获得其他账号、root或Docker宿主权限。
- Agent权限与用户交互终端独立。手动终端使用主机执行账号权限。星屿的邮件/联系人等发送操作仍使用固定预览确认，完全权限不会绕过这层确认。

权限和思考由原生会话日志保存，重新打开读取真实状态，不从浏览器恢复失效授权。应用会按账号/服务器保存上次Pi/DSH引擎、服务器/本地/远程电脑对话；旧窗口选择迁移一次。暂时断网保留记录；对话确已不存在时回到可用对话/新对话，不能仅凭缩短的目录断定历史消失。恢复视图不提交、重放或迁移任务。

## 接口与边界

均在已鉴权的`/api/agent/remote/conversations/:id`下，先验证当前账号及不可变原生绑定，再验证当前登录仍有效。没有任意RPC、命令行、cwd、shell路径或授权凭据入口。

| 路由 | 方法 | 行为 |
| --- | --- | --- |
| `/controls` | GET | 读取原生模型/思考、权限、技能和终端目录；失败域独立，不假称支持 |
| `/controls` | POST | 严格`{id,kind:"thinking"或"permission",value}`；只接受真实目录值、固定原生命令并核对回执 |
| `/terminals` | GET/POST | 当前登录的终端列表；`{id,terminalId,cols,rows}`创建一次 |
| `/terminals/:terminalId` | GET | 有界输出/状态，`cursor`补回，不执行输入 |
| `/terminals/:terminalId/input` | POST | `{id,data}`，序列化且不自动重试 |
| `/terminals/:terminalId/resize` | POST | `{id,cols,rows}`，受主机及应用上限约束 |
| `/terminals/:terminalId/close` | POST | `{id}`请求原生进程范围终止，确认后才显示结束 |

沿用`dsh_actions`按账号、对话、操作ID及内容摘要记账；断流/超时留下未知结果，不重发。设置和终端写操作走不重试的Remote RPC，禁止响应过大后的传输回退重放。终端绑定登录Hash/连接/会话，输出2MiB有界，每账号最多8个/全局64个；异步查询后原子预留，防止并发绕过数量上限。

终端连续10分钟未使用、退出登录、凭据撤销或连接断开后撤销输入并请求清理；无法联系主机时不宣称进程已停止，后续重新认证的连接只补清理，不恢复输入/重建进程。Agent任务、原生权限及Pi进程不由终端面板重新启动。

`app_functions`的`assistant.runtime`已补充DSH真实模型/思考、权限与附件限额查询。附件继续复用已注册的`attachments.list/read`和原生文件工具，技能与命令执行沿用原生域；不向模型提供扩大自己权限的按钮或任意终端RPC。
