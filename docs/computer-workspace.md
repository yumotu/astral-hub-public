# 电脑工作区

桌面版在设置中的「电脑连接」开启本机执行器，由本机用户选择项目目录并分别授予修改与命令权限。默认不开启，不自动继承独立命令行执行器授权。

另一台电脑可使用 Release 中的远程执行器包，先阅读包内 README，通过本机交互完成配对和目录授权。不要发送或提交生成的 `device.json`。重复配对提示已有配置时，应管理原设备，避免重复创建设备。

服务器项目、本机项目和远程电脑项目在同一助手入口展示。设置收进工具栏面板；终端始终指向所选电脑，对话可右键或长按管理，项目先展示最近三个对话。

聊天支持附件输入及原件回传；文本提取包括 PDF、Word、Excel。传输按账号/项目/当前任务授权并校验摘要，撤销后拒绝访问。插件许愿是描述需求→查找已有来源→固定版本及权限预览→确认安装，不将第三方内容当成用户指令。

电脑 Shell 使用当前系统用户的完整权限，项目目录不是 Shell 沙箱。旧版未声明附件/思考能力时会提示更新，不伪造读取结果，也不把离线电脑任务转移到服务器执行。
