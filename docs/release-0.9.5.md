# 星屿 0.9.5

## 投资持仓与金融工具

- 投资首页默认显示资产总览、分类卡片、我的持仓和 AI 建议
- 持仓首页在手机端使用单列布局，长名称、金额和指标不会逐字换行
- 支持自然语言生成持仓交易草稿，例如买入、卖出、定投和赎回记录
- 交易草稿确认后写入账号级持仓账本，并保留原始描述、来源和状态
- 增加行情同步与 AI 建议的半小时定时任务
- 增加持仓、交易草稿、任务和建议接口
- DSH 投资工具增加持仓意图记录、报价刷新预览和交易预览
- Pi `app_functions` 同步提供研究、持仓、自然语言记账、报价、建议和定时任务工具；持仓记账与定时任务沿用确认门槛
- 交易预览不会直接提交真实订单，真实连接器仍需单独配置和授权

## 兼容与限制

- 基金估算净值和官方净值分开保存
- 申购、赎回和定投记录保存提交、计价、确认和交收状态
- 支付宝个人账户自动读取仍采用导入优先方案，系统不保存支付宝密码、Cookie 或扫码会话
- macOS 使用临时签名，Windows 未正式签名，Android 使用新的调试签名
