## 本地开发

需要 Node.js 24 或更新版本。

```sh
npm ci
npm run init
npm run dev
```

配置 `.env` 中的 `APP_TOKEN`。服务器模式可配置 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_MODEL`；本机模式在当前设备界面填写 Key，设备 Key 不进入同步请求或服务器数据库。

```sh
npm test
npm run build
npm start
```

本地 Pi 集成需要独立运行 `deploy/pi` 中的服务，并在应用环境设置 `PI_BRIDGE_URL`、`PI_BRIDGE_TOKEN`。普通本地开发没有 Pi 服务时，塔罗、本机 AI 与账户/社交功能仍可单独使用。

## 边界与数据

服务器保存账号、手记、联系人聊天、最新有效位置快照和 Pi 历史；不提供端到端加密。DeepSeek 默认由服务器调用；选择本机直连后，塔罗和文本插件直接请求官方 API。Pi 始终由远程服务处理。网页 Pi 入口按项目权限提供文件工具；SSH 的 Pi CLI 在独立容器工作区运行。

服务器持久卷不可随意删除。部署前备份 SQLite 与 `.env`，不要执行 `docker compose down -v`。源码、运行包与 Docker 构建排除本机 `.env`、私有数据与密钥文件。每次版本更新的交接记录见[版本交接索引](docs/handoffs.md)。

0.7.1 新增[后台任务与消息队列](docs/background-tasks.md)：执行中继续输入、排队编辑/撤回、原生Pi任务补充、自由切换聊天与断线进度补回。

0.7.4 修复项目技能安装入口：管理员在对应项目聊天发送 `/skills 安装 skills`，可导入标准 SKILL.md、附带脚本和参考资料，校验后持久启用。Bash 通过只读 `/skills/<技能名>` 使用资源，临时 HOME 不承担安装目录的作用。用法见[账号与 Pi](docs/accounts-and-pi.md)。

### Pi 插件与项目访问

管理员可以直接在聊天中让 Pi 查找并安装、列出、更新或移除 Pi 原生包；新安装的扩展和技能在下一轮加载。插件由 Pi 官方包管理器安装，可持久保存。原生插件在 Pi 进程中运行，拥有该进程可访问的项目文件与环境变量；询问模式只约束星屿内置工具，不限制插件自身行为。请只安装可信来源。其他账户暂不加载或管理这些原生插件。

服务器 Pi 当前可访问配置的全部项目目录，智能体模式可修改它们；项目文件仍使用内置工具的备份与恢复机制，Bash 和原生插件的直接修改不会自动计入文件变更汇总。后续可按用户和应用细化权限。
